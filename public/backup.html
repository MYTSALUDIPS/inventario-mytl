💾 Respaldo de Base de Datos

Desde aquí puedes generar una copia de seguridad completa de tu base de datos inventario_myt.

Se descargará un archivo con extensión .sql que contiene toda la estructura y los datos actuales.

ℹ️ Recomendación

Guarda este archivo en un lugar seguro o en la nube. Puedes restaurarlo fácilmente desde phpMyAdmin o la consola de MariaDB con el comando:

mysql -u root -p inventario_myt < backup_fecha.sql
